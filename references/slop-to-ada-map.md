# Slop → Award Map

Each AI-slop pattern, why it reads as generic on Apple platforms, and which ADA apps show the better path. Section 1 tells you how to *spot* each pattern; section 2 is the map; section 3 lists quick heuristic questions.

## 1. Detection signals

Pattern numbers refer to the table in section 2. A signal is a reason to look closer, not an automatic finding: a gradient that encodes real data (#1) or a custom tab bar in a game (#5) can be legitimate.

| # | In code (SwiftUI / UIKit) | In screenshots |
|---|---|---|
| 1 | `LinearGradient`/`RadialGradient`/`MeshGradient` as a full-screen or root background; purple/indigo/pink `Color(red:…)` literals; `.blur` blobs | Purple→blue or pink→purple wash behind everything; glows with no meaning |
| 2 | Same `.background(...)` + `.cornerRadius`/`.clipShape(RoundedRectangle)` + `.shadow` on every row/container; cards nested in cards | Uniform grid of shadowed rounded rectangles; no clear first/second/third read |
| 3 | Emoji inside `Text` used as icons or buttons; icon fonts; `Image("ic_…")` sets with mixed styles where `Image(systemName:)` would fit | Emoji in buttons/tabs/headers; icons with mismatched weights and baselines |
| 4 | `.font(.system(size:))`, `UIFont.systemFont(ofSize:)`, fixed `.frame(height:)` on text containers, `.lineLimit(1)` on body copy; no `.title`/`.body`/`@ScaledMetric` | Every label the same few sizes; nothing suggests it scales; tiny secondary text |
| 5 | Hand-built tab bar (`HStack` of buttons + `selectedTab`) instead of `TabView`; custom back buttons; `navigationBarHidden(true)` everywhere; drawers | Floating pill "tab bar" made of emoji/icons; hamburger menu; no nav bar or large title |
| 6 | Tap targets < 44pt; hover-only affordances; `ScrollView` pages behaving like web sections; no `.sensoryFeedback` | Looks like a responsive website; tiny links; CSS-style shadows |
| 7 | Multi-page `TabView(.page)` onboarding before content; auth gate as root view | "Welcome to X" carousel; sign-up wall before any value |
| 8 | Home view with many equal-weight stat tiles / charts / rings | Dashboard of tiles all the same size and emphasis |
| 9 | Settings toggles and options for everything on the main screen | Crowded toolbars; every option visible at once |
| 10 | String literals like "Let's crush your goals", "Unlock your potential", "✨ Welcome Back! ✨" | Hype copy with exclamation marks and sparkles; no consistent voice |
| 11 | Mixed illustration assets of different styles | Stock/AI illustrations that don't match each other or the task |
| 12 | `.animation(.spring())` on everything; same `.transition(.opacity.combined(with: .slide))` everywhere; no `accessibilityReduceMotion` check | Everything bounces or fades the same way |
| 13 | No `.sensoryFeedback` / `UIImpactFeedbackGenerator`, or one generic impact everywhere | (Not visible; ask or check code) |
| 14 | State shown only by `.foregroundColor(.green/.red)` or tint; no icon/label change | Red/green status dots with no text or shape difference |
| 15 | Hard-coded `.white`/`.black` text, opaque custom bars, no `Color(.systemBackground)`/semantic colors, no `.background(.regularMaterial)` or glass where appropriate; no dark-mode assets | Breaks or looks odd in dark mode; heavy opaque bars on iOS 26-era design |
| 16 | No WidgetKit / ActivityKit / App Intents targets in the project | (Ask) No widgets, Live Activities, or Shortcuts |
| 17 | No `horizontalSizeClass` handling, no `NavigationSplitView` on iPad/Mac; Mac app is a stretched iOS view | Single centered phone column on iPad/Mac |
| 18 | visionOS target that only uses `WindowGroup` with flat panels | Flat iPad window floating in space |
| 19 | Plain `ProgressView()` during long AI/network work | Generic spinner/skeleton for seconds at a time |
| 20 | `if items.isEmpty { Text("No items yet") }` | Grey icon + "Nothing here" |
| 21 | Everything default (`.accentColor(.blue)`, plain `List`) with zero custom identity | Correct but anonymous; could be any app |
| 22 | Streak counters, confetti, badges unrelated to the domain's real goals | 🔥 streaks and trophies stuck onto a utility |
| 23 | Login/paywall as the first screen; analytics SDKs on by default | Account wall or paywall before trying anything |
| 24 | Re-implementation of a system app with no differentiating idea | "Modern minimal" timer/weather/calculator |

## 2. The map

Each entry gives the slop pattern, why it reads as generic on Apple platforms, and which ADA winners show the better path.

| # | Anti-pattern (AI slop) | Why it fails on Apple platforms | Better alternative, shown by |
|---|---|---|---|
| 1 | **Default purple/indigo-to-pink gradient hero backgrounds**, glows, and "aurora" blobs with no tie to the domain | The color carries no meaning, the same look appears in every category, and it fights system materials | **Tide Guide** (palette tracks real sky color through the day); **Halide** (one yellow accent with a clear meaning: active state); **Pok Pok** (strict three-color palette); **Neva** (palette per level as storytelling). If you use gradients, make them content-driven, like **Denim**'s mesh gradients generated from playlist art or **Any Distance**'s Metal swirl as a brand element. |
| 2 | **Card-everything layouts**: every item in a rounded, shadowed card on a grey background in a uniform grid | Erases hierarchy. Recipe, weather, and finance apps all look the same | **Crouton** ("organization and information hierarchy"; only the current step); **Flighty** ("one line per flight," airport-board rows); **Slopes** ("pick what matters to tell the story"); **iA Writer** (text-first, no chrome). Cards are fine when they mean something physical: the **Bears Gratitude** prompt cards are flipped like real cards, and the **CapWords** stickers. |
| 3 | **Emoji or random icon-font glyphs used as UI icons** | Inconsistent weight and baseline, no Dynamic Type scaling, no accessibility labels, off-platform look | **Any Distance** ("draws heavily on SF Symbols"); **Darkroom** ("evergreen symbols and simple highlight colors"); **Procreate** ("Iconography is a universal language"). Custom icon sets are fine only when they're a *full* system, like **grug**'s hand-drawn icons from the same stroke engine. |
| 4 | **Ignoring Dynamic Type**: fixed pixel font sizes, text that truncates or overlaps at accessibility sizes | Apple names Dynamic Type in nearly every Inclusivity citation | **Guitar Wiz**, **Oko** ("flawless VoiceOver and Dynamic Type implementation"), **Universe** ("fantastic implementation of Dynamic Type"), **Speechify**, **Land of Livia**, **Procreate**. |
| 5 | **Non-native navigation**: hamburger drawers, web-style top nav bars, custom back buttons, no swipe-back, modal-on-modal stacks | Breaks muscle memory and system gestures. Apple's Interaction category literally means "perfectly tailored to their platform" | **Crouton** ("leaned on platform conventions"); **Rooms** (native sliders and bottom navigation on top of Unity, the "chef's kiss"); **Headspace** (simplified tab structure: Today and Explore); **Tide Guide** (the developer unlearned "non-standard navigation"); **Duolingo** (one clear "path"). |
| 6 | **Web-like UI in a native shell**: hover-style affordances, tiny tap targets, CSS-looking shadows, page-like scrolling, no haptics | Feels like a website, and none of the platform features show up | **Flighty**, **Mela**, **Things 3**: deep platform integration (Live Activities, Dynamic Island, Reminders, Calendar, Shortcuts). **Darkroom**: keyboard, trackpad, Files, extensions. Even web-born **Rooms** went native on mobile. |
| 7 | **Generic "Welcome to [App]" multi-page onboarding carousels** plus a mandatory account wall before any value | Delays value. Winners let people start right away | **Bears Gratitude** (no sign-in; "go straight into the experience and start writing"); **grug** (no login); **Moonlitt** ("easy onboarding"); **Skate City**, **Rytmos** (teach by doing, lessons spaced out); **Pine Hearts** (onboarding is where accessibility settings are surfaced). |
| 8 | **Dashboard of everything**: stat tiles, rings, and charts all at equal weight on the home screen | Overwhelms. No story | **Slopes** ("easy to overwhelm with stats… pick what matters"); **The Outsiders** (one Readiness Score); **Headspace** (one-tap Today tab); **Guitar Wiz** (progressive disclosure). |
| 9 | **Feature-maximalism**: settings and options for everything shown up front | Raises cognitive load and dilutes the core loop | **Oko** (cut features to stay simple); **Crouton** ("what to leave out"); **Halide** (advanced settings "a few taps away," not on screen); **Darkroom** (advanced features "behind an explicit action"); **Primary** ("properly minimal UI"). |
| 10 | **Personality-free, interchangeable copy** ("Get started," "Unlock your potential," "Seamlessly manage…") | Sounds like every AI landing page and builds no relationship | **grug** (a whole voice system, even the release notes); **CARROT Weather** ("humorous forecasts"); **Bears Gratitude** (prompts in the user's voice); **Duolingo** (characters with distinct personalities); **Headspace** (plain-language labels with clear purposes). |
| 11 | **Stock or AI-generated illustration with no consistent style**, or decoration that doesn't help the task | Reads as filler. Winners' art carries the content | **Vocabulary** ("charming, consistent illustrations that create a clean visual style and rhythm"); **Headspace** ("recognizable, comfortable illustration style"); **Bears Gratitude** (art is the reason the app exists); **Rebel Girls** (art "tailored for the stories and interface"); **Katha Room** (Gond art form). |
| 12 | **Default springy animations everywhere / motion for its own sake** (everything fades and slides in the same way) | Motion with no meaning is noise and ignores Reduce Motion | **grug** (text writes like ink, so motion carries meaning); **CapWords** (a micro-animation masks AI latency); **Odio** (animation in sync with the sound); **Loóna** (calming, precise animation); **puffies.** and **stitch.** (Reduce Motion support). |
| 13 | **No haptics, or the same generic haptic tap everywhere** | A missed channel. Apple cites custom haptics constantly | **(Not Boring) Habits** (layered, iterated haptics on the key action); **PowerWash** (a haptic per nozzle); **(Not Boring) Camera** (haptic scroll wheels); **Opal** (haptics when unlocking gems); **Oko** (haptics as the safety-critical signal). |
| 14 | **Color as the only signal for state** (red/green status, toggles told apart by tint alone) | Fails Differentiate Without Color and color-blind users | **Guitar Wiz** (Differentiate Without Color; black-and-white diagrams under Increase Contrast); **Halide** (found color alone confused the RAW state and redesigned the button states); **stitch.**, **Procreate** (color-blindness options); **Ground News** (bias markers color-coded *and* labeled/graphed). |
| 15 | **Hard-coded light-only or dark-only palettes, opaque custom bars that fight Liquid Glass / system materials** (2025+ design) | Looks dated next to iOS 26-era apps and breaks vibrancy and contrast | **Moonlitt** ("best-in-class Liquid Glass integration… like the interface was breathing"); **Tide Guide** ("integrates the new design and Liquid Glass… tying nicely into the aquatic theme"). |
| 16 | **App ends at the app icon**: no widgets, Live Activities, Watch, or Shortcuts | Misses the surfaces Apple rewards most in Interaction and Delight | **Flighty** (Live Activities, Dynamic Island, Lock Screen widgets, Siri, Calendar); **Tide Guide** (widgets, complications, Dynamic Island); **Lumy** ("elegant widgets and Live Activities"); **Mela** (Dynamic Island timers); **CARROT** (widgets, watch faces); **Guitar Wiz** (Smart Stack, App Intents). |
| 17 | **iPhone layout stretched onto iPad/Mac** (giant single column, phone-sized controls on a 13" screen) | "Scaled up" is the opposite of what Apple praises | **Guitar Wiz** ("optimized for iPad and Mac rather than simply scaled up"); **Halide** (iPad version "designed specifically for the platform"); **Darkroom** (more controls on iPad); **Procreate / Procreate Dreams / Feather** (Pencil-first iPad design). |
| 18 | **Flat 2D panels floated in visionOS** (an iPad app dropped into space) | Wastes the spatial canvas | **Taobao** (3D products with considered "placement, position, controls, size"); **NBA** (3D scoreboards floating by the action); **Blackbox** (uses "every corner of the spatial canvas"); **djay** (immersive environment tuned for flow); **Primary** (spatial video with minimal chrome). |
| 19 | **Generic spinner or skeleton while AI works** | Dead time that feels mechanical | **CapWords** (a micro-animation while the model runs); **Capybara** (a relaxed capybara "hangs out on the screen while the app is doing its thing"); **Detail** (camera-app simplicity hides the processing). |
| 20 | **Empty, joyless empty states** ("No items yet." + grey icon) | Misses the first chance to show personality and teach | **Bears Gratitude** (prompts and bears fill the blank page); **Rooms** (start from a template or an empty room, and the 404 page is a wall-less room people remix); **Duolingo** (characters cheer on progress). *(Note: no Apple citation discusses empty states directly. This entry is inferred from the onboarding and personality patterns.)* |
| 21 | **Brand-less sameness**: SF Pro + system blue + an SF Symbol tab bar and nothing else (the "native but anonymous" failure) | Native without a point of view is a different kind of slop | **(Not Boring) Habits/Weather/Camera** ("big loud capital-V Vibes" on standard controls); **Halide** (a film-camera identity); **Flighty** (airport-board identity); **Any Distance** (the signature oval photo mask). |
| 22 | **Gamification bolted on** (badges, streaks, and confetti unrelated to the domain) | Feels manipulative and generic | **(Not Boring) Habits** (a 66-day hero's journey grounded in habit research); **Duolingo** (characters and the path are part of learning); **Slopes** (the "meet the Slopes guy" pin and real ski achievements); **Any Distance** (collectibles tied to real activity). |
| 23 | **Login/paywall before value, data collection by default** | Breaks trust; winners show restraint | **grug**, **Bears Gratitude** (no login); **Any Distance** (route clipping on by default; data stays in HealthKit); **Harvee**, **Oko**, **Hearing Buddy** (on-device processing). |
| 24 | **Interchangeable metaphor-free utility** (a "modern minimal" calculator, weather, or timer with nothing to say) | No reason to exist next to the system app | **Calzy** (2018) (deep OS integration); **CARROT** (humor); **Tide Guide** (sky-matched palette, layered depth); **Moonlitt** (removes complexity); **Vocabulary** (quiet perfection). |

## 3. Quick heuristics
- **"Could I swap the logo and ship this as a different app in a different category?"** If yes, it's slop. Winners can be identified by their concept alone.
- **"What real-world object or ritual is this UI modeled on?"** Winners almost always have an answer.
- **"What did you leave out?"** Winners can list the cuts.
- **"Where does the app live besides its own screen?"** Look for widgets, Live Activities, Watch, Siri/App Intents, Share sheet.
- **"Turn on AX5 Dynamic Type, VoiceOver, Increase Contrast, Differentiate Without Color, and Reduce Motion. Does the design still hold up?"**
- **"Is there one signature interaction that's been iterated past 'fine'?"**
- **"Is the navigation the platform's, with personality layered on top, or invented?"**
